# 株温計（かぶおんけい） - プロジェクト仕様書

## 1. プロジェクト概要

### サービス名
**株温計（かぶおんけい）**
- 画数: 31画（大吉 - 頭領運。リーダーシップ＋協調）
- 内訳: 株(10) + 温(12) + 計(9)
- ドメイン候補: kabuonkei.com / kabuonkei.jp

### コンセプト
「日本語版 Fear & Greed ダッシュボード」― 市場の温度を測る
- 市場のセンチメント（恐怖・欲望）を示す複数の指標を **1画面で俯瞰できる** 日本語Webサービス
- 収益モデル：Google AdSense（金融系はCPC高め、RPM 300-500円想定）
- ターゲット：日本の個人投資家（日本株・米国株問わず幅広い層）
- キャッチコピー案: 「今日の相場、熱い？冷たい？」

### なぜこのアイデアか（市場調査の結論）
- VIX、Fear & Greed Index、騰落レシオ、信用倍率等を **1画面にまとめた日本語サイトが存在しない**
- 最大手 nikkei225jp.com（月間3,000万訪問）ですら各指標が別ページにバラバラ
- 株式マーケットデータ（stock-marketdata.com）は網羅的だが辞書的UIでダッシュボードではない
- 「恐怖指数 まとめ」「Fear and Greed Index 日本語」等のキーワードで満足のいくサイトがない
- SEO的に個人サイトが狙える隙間がある

### 競合分析
| サイト | 強み | 弱み |
|--------|------|------|
| nikkei225jp.com | 圧倒的なデータ量・ドメインパワー | 指標が別ページ。一覧性なし |
| stock-marketdata.com | 網羅的な指標解説 | 辞書的UI。ダッシュボード型ではない |
| TradingView | 高機能チャート | 英語UI中心。センチメント指標は弱い |
| chartpark.com | VIXチャート | VIXのみ。他指標なし |

## 3. フェーズ分け

### Phase 1: MVP（月額0円）- 最優先
無料APIのみで構築。「日本語版 Fear & Greed ダッシュボード」としてローンチ。

**掲載指標：**
1. **CNN Fear & Greed Index** - メインのゲージ表示（0-100）
   - 7つのサブ指標も表示（Market Momentum, Stock Price Strength, Stock Price Breadth, Put/Call Ratio, Market Volatility, Safe Haven Demand, Junk Bond Demand）
2. **VIX（恐怖指数）** - 現在値 + 日足チャート
3. **日経VI** - 現在値 + 日足チャート
4. **主要指数の騰落** - S&P500, ダウ, ナスダック, 日経平均, TOPIX
5. **米国債利回り**（10年債）- チャート付き
6. **ドル円為替** - 現在値

### Phase 2: 拡張（月額3,300円 - J-Quants Standard）
PVが伸びてきたら追加。

**追加指標：**
7. **騰落レシオ**（プライム市場）
8. **空売り比率**（業種別）
9. **信用倍率**（信用買い残 / 信用売り残）
10. **投資主体別売買動向**（海外投資家・個人・信託銀行など）
11. **裁定買い残 / 売り残**

### Phase 3: 差別化機能
12. 独自の「日本版 Fear & Greed Index」（複数指標を組み合わせた独自スコア）
13. 指標のアラート通知（メール or LINE）
14. 過去データとの比較（「リーマンショック時はこの水準だった」等）

### データ取得アーキテクチャ

```
[Vercel Cron / GitHub Actions]
         │
         ▼
[Python スクリプト（yfinance + fear-and-greed）]
         │
         ▼
[JSON ファイル or Vercel KV にキャッシュ]
         │
         ▼
[Next.js API Routes → フロントエンドに配信]
```

**重要な設計判断：**
- yfinanceはPythonライブラリなので、データ取得は **Python スクリプトをGitHub Actionsで定期実行** → JSONをリポジトリにcommit or 外部ストレージに保存 → Next.jsがそれを読む、という構成が現実的
- あるいは **Next.js API Route内でyfinance互換のNode.jsライブラリ（yahoo-finance2）を使う** 方法もある
- yahoo-finance2 (npm): https://github.com/gadicc/node-yahoo-finance - Node.js用のYahoo Financeラッパー。yfinanceと同等のことがNode.jsでできる

### Node.js統一構成（推奨）

Python依存を避けたい場合：
```
[Vercel Cron]
    │
    ▼
[Next.js API Route]
    ├── yahoo-finance2 (npm) → VIX, 日経平均, 為替など
    ├── fetch → CNN Fear & Greed Index (JSON endpoint)
    └── J-Quants API (Phase 2) → fetch で直接呼び出し
    │
    ▼
[Vercel KV or ISR キャッシュ]
    │
    ▼
[フロントエンド表示]
```

## 9. 注意事項

### yfinance / yahoo-finance2 の利用について
- 非公式APIのため、Yahoo側の変更で突然動かなくなるリスクがある
- 商用利用の可否はグレー。Yahoo Financeの利用規約を要確認
- バックアップとして Financial Modeling Prep（無料枠250リクエスト/日）も検討

### Fear & Greed Index について
- CNN のデータを利用する場合、「出典: CNN Business」の明記が望ましい
- 独自に7指標相当を計算する「日本版 Fear & Greed Index」を作れば依存を減らせる

### 法的な免責事項
- 「当サイトは投資助言を行うものではありません」等の免責事項を必ず掲載
- 金融商品取引法上の問題がないか確認（情報提供のみなら基本的にOK）

### 広告について
- Google AdSense は審査に通常2-4週間
- 最低限のコンテンツ量（10ページ程度）と独自性が必要
- YMYL（Your Money or Your Life）カテゴリのため、E-E-A-T を意識
