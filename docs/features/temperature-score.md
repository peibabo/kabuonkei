# 温度スコアの2本立て

株温計には2種類の市場温度スコアがある。

## Fear & Greed（米国版）
- ソース: CNN Fear & Greed API（bot検知でブロックされた場合はVIXベースの簡易推定にフォールバック）
- 計算: `src/lib/fear-greed.ts::fetchFearGreedIndex()` / `estimateFearGreedFromVix()`
- 実質的に米国市場（S&P500）のセンチメントを示す

## 市場温度（日本版）

**市場温度 = C1（日経225 の終値と、直前 125 営業日の移動平均との乖離）だけ**で決める。需給データは「需給の温度」として別に表示し、市場温度には混ぜない。2026-11-17 に 5 要素の等ウェイト平均からこの形に切り替えた。

### 市場温度（C1）

- 乖離率 ±15% を 0 / 100 に線形マップして clamp（`JAPAN_FG_THRESHOLDS.nikkeiMaDeviationPct`）。移動平均は当日を含まない直前 125 本
- ライブ: `computeJapanFearGreed()`（`src/lib/japan-fear-greed/compute.ts`）。`score` / `level` が市場温度。移動平均はチャート末尾（= 現在値と同じ立会日）を除いて取り、過去推移と同じ値になる
- 過去推移・過去統計・類似日・業種ヒートマップ: `scripts/_lib/japan-temperature.ts::computeJapanTemperatureSeries()`（4 つの生成スクリプトで共通）
- ゲージ・推移チャート・前日比・連続日数・アラート・ポートフォリオ・過去 10 年中の位置は、すべてこの 1 つの定義

### 需給の温度（参考表示）

- 2 要素の単純平均（取れた要素だけで平均。1 つも取れなければ `supply: null`）
  1. **海外投資家フロー**: 直近 4 週の売買差引累計。±2 兆円 → 0 / 100（`foreignFlow4wOkuYen`）
  2. **信用買い残の増減**: 買い残の 4 週変化率。±15% → 0 / 100（`marginBuyChange4wPct`）。JPX のページは直近約 5 週しか載らないため、`mergeMarginWeeks()` で `margin-ratio-history.json` の長期履歴を足してから計算する
- JPX の週次公表データなので 1〜2 週遅れて動く。ゲージ下の別枠に表示し、市場温度・アラートには使わない
- 検証できた要素だけを市場温度側へ足していく方針。2026-11-20 に将来リターンとの関係を試算した結果（`npm run analyze:supply`。JPX の公表は大引け以降なので、各週は公表後最初の水・木曜の翌営業日から使う）、**市場温度に足す根拠は見つからず、参考表示のまま**とした:
  - 順位相関は 1・3・6 か月後のどれでも |ρ| ≤ 0.12 と弱く、市場温度（C1）の帯の中で見ても変わらない
  - 需給の温度 ≤20 の日の 3 か月後は基準 +1.9% だが、前半（2016-02〜2021-06）+5.4% / 後半（2021-06〜）-4.8% と向きが逆になり、回数も 9 回しかない
  - C1 ≤20 の局面で、需給も冷たい回（6 回）とそうでない回（8 回）の 3 か月後は +11.8% と +11.5% で差がない
  - 信用買い残の急減（≤20）は 2002 年以降で 6 か月後が基準 -4.3%。投げ売り＝底とは言えず、2007〜08 年のように下げが続く局面でも出る（後半 2014-10〜は基準 +2.5% と逆）
  - 海外投資家フローは両端（≤20・≥81）がともに基準を上回る U 字で、一方向の意味は付けにくい

### 5 要素版をやめた理由（2026-11）

- **需給 3 要素が高止まりし、急落を映さなかった**: 2026-11-06（日経 -5.96%）に総合 65°（過熱）のまま。内訳は C1=7 / C5=38 / C2=100 / C3=100 / C4=79。5 要素が揃った 148 日で総合の最低は 44 で、極寒（≤20）に事実上届かなかった
- **C4 裁定残バランスは根拠が弱かった**: 比率（買残 ÷（買残 + 売残））は 0.93〜1.00 の狭い幅でしか動かず、閾値は推定値のまま。5 要素がそろった 149 日では 4〜6 月と 10 月以降が 77〜100 に高止まりし、7〜9 月だけ 35〜59 に下がった。11/6 の急落日も 79 と高く、長期履歴がないため将来リターンとの関係も確かめられない
- **C3 信用倍率（水準）は時代で基準がずれ、急落初週にむしろ上がる**: 売残の買い戻しが先に進むため。投げ売りを拾うのは買残の変化（`npm run analyze:margin-score`）。この結果から需給の温度では買残の 4 週変化を使う
- **C5 ドル円モメンタムを足すと悪くなる**: 2007-07 以降 4731 営業日の試算（`npm run analyze:jp-composition`）で、C1+C5 は C1 単独に比べて極寒通知が多く（72 回 vs 41 回）、通知後の日経225 のリターンが低く（3 か月後 +0.1% vs +1.8%、全日の基準は +2.3%）、前日比 -5% 以下の日を極寒として拾えた数も少ない（21 日 vs 23 日）
- **スコアが 3 種類に割れていた**: ゲージは 5 要素、過去統計・類似日は C1+C5、アラートは C1 で、ゲージの横の「過去 10 年中の位置」も別基準と比べていた

### 限界

- C1 が「良い」と示せたわけではない。極寒通知の後のリターンは基準を明確には上回らず、過熱側はその後のリターンが基準以上で、「過熱 = 警戒」の裏づけはない
- 高値圏からの急落（2013-05-23、2016-11-09、2026-03-09 など）は温度では拾えない

### 旧 5 要素版の記録

- `src/data/japan-fg-snapshots.json`（2026-04-17〜11-16）は記録として残すが、画面では使わない。値は書き換えない
- 旧要素の正規化関数（`normalizeMarginRatio` / `normalizeArbitrageBalance` / `normalizeUsdJpyMomentum`）と閾値は、過去スナップショットの再計算（`scripts/_lib/snapshot-backfill.ts`）と試算スクリプトのために残している

### UI

- `src/components/FearGreedGauge.tsx`（`market: "us" | "jp"` の判別ユニオン prop で日米共通。PC は左=日本版 / 右=米国版の 2 列配置。見出しは 🇯🇵 / 🇺🇸 の国旗絵文字付きで国識別を明示）
- 日本版はスコアの下に「日経225 は 125 日移動平均から -13.0%」と乖離率を出し、その下の別枠に需給の温度と内訳（海外投資家フロー・信用買い残の増減）を出す
