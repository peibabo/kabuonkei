# ASP 申請キット（2026-07 作成）

収益化方針（アフィリエイト主軸・月 3 万円目安）の初手として、ASP への登録申請を最短で済ませるためのコピペ素材集。**審査〜提携承認に 2〜4 週間かかるため、流入規模に関係なく先に申請しておく**のがこのキットの目的。

## 1. 登録する ASP（優先順）

| 優先 | ASP | 理由 | 審査 |
|---|---|---|---|
| 1 | **A8.net** | 国内最大手。FX・証券・ロボアド案件が最も豊富 | サイト審査なし（即日登録可）。ただし広告主ごとの提携審査あり |
| 2 | **もしもアフィリエイト** | Amazon・楽天の物販（投資書籍）を一本化できる。W報酬制度 | サイト審査あり（数日〜1週間） |
| 3 | **アクセストレード** | 金融（FX・証券）に伝統的に強く、A8 に無い案件を補完 | サイト審査あり |
| 4 | バリューコマース（任意） | 大手広告主系。後回しで可 | サイト審査あり |

Amazon アソシエイト直接契約は「180日以内に3件の売上」条件があるため、**まず「もしも」経由で Amazon リンクを使う**のが定石。

## 3. 提携申請する案件カテゴリ（承認され次第、優先順）

案件の有無・報酬額は変動するため、**ASP 登録後に管理画面で検索して選定**する。方針メモ（memory: 収益化戦略）との対応：

1. **FX口座開設**（単価 1〜3 万円）— ドル円モメンタムが温度要素にあり文脈適合が最も高い。例: GMOクリック証券FX / DMM FX / 外為どっとコム / みんなのFX
2. **証券サブ口座・IPO用口座**（単価 3千〜2万円）— 主口座アフィは避け、「2つ目の口座」文脈で。例: 松井証券 / moomoo証券 / SBIネオトレード / 岡三オンライン
3. **投資書籍**（もしも経由 Amazon/楽天、料率 2〜4%）— 『敗者のゲーム』『ウォール街のランダム・ウォーカー』等。learn/analysis 記事の末尾と親和性が高い
4. **ロボアド**（単価 5千〜1.5万円）— WealthNavi / SUSTEN 等。「温度を見て売買したくない人向け」の逆張り文脈
5. **経済メディア購読** — 日経電子版等（案件があれば）

### /privacy 追記ドラフト（要レビュー）

> **広告配信について**
> 当サイトは、アフィリエイトプログラム（A8.net、もしもアフィリエイト等）に参加しています。広告リンクを経由してサービスの申込・商品の購入が行われた場合、運営者は広告主から成果報酬を受け取ることがあります。アフィリエイトリンクの掲載箇所には「PR」等の表示を行います。また、第三者配信の広告サービスを利用する場合、Cookie を使用してユーザーの過去のアクセス情報に基づく広告配信が行われることがあります。

## 5. サイト側の掲載原則（実装時に参照）

1. **極端温度（≤20 / ≥80）のときだけ導線を出す** — 平時は非表示。嫌味にならず転換率も高いタイミングに限定
2. **「PR」表記を必ず付ける**（景品表示法・ステマ規制対応、2023年10月〜義務化）
3. **断定的判断の提供をしない** — 「儲かる」「必ず」等は不使用。投資助言・代理業に該当する表現を避ける（利用規約第9条と整合）
4. 掲載面の第一候補: `/analysis` 記事末尾 → `/events` 解説末尾 → 極端温度時のダッシュボード（この順で段階導入）
